# fluxatlas

Interactive explorer for FLUXNET-standardized ecosystem data.

`fluxatlas` builds a standalone, browsable page from the FLUXNET-standardized
output of an eddy covariance site — fluxes, meteorology and their quality
flags — resolved from the whole record down to the single day.
